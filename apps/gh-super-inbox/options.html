GitHub Super Inbox

Shows why each PR is still in your notifications inbox and highlights the ones that merged after you approved them.

The extension reads pull request state and your own reviews through the GitHub API, so it needs a token. The token stays in this browser's extension storage and is only ever sent to api.github.com.

Get a token

If you use the gh CLI, run gh auth token and paste the output.

Otherwise create a classic personal access token with the repo scope (needed to read private repos). A fine-grained token also works if it has Pull requests: read and Metadata: read on the repos you review (use Pull requests: read and write if you want the Mark tests viewed button). If your org uses SAML SSO, authorize the token for that org.

How it decides

A PR counts as merged with your approval only when it is merged and your own latest review on it is an approval submitted before the merge. Other people's approvals don't count. If your approval was dismissed, or you later requested changes, it doesn't count either.

Results are cached: merged PRs for 7 days, closed PRs for an hour, open PRs for 2 minutes. The ↻ button on the notifications page re-checks the current page.
